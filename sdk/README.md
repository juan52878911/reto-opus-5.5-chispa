# SDK de Chispa

- `python/` — SDK de Python.
- `movil/` — `chispamovil`, el núcleo Go de los SDK móviles (gomobile).
- `android/` — biblioteca Kotlin + demo; se compila en AWS.
- `ios/` — paquete Swift; escrito sin compilar (README con el comando para una mac2).
